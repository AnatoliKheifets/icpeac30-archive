# ICPEAC XXX website archive

This repository preserves the website of the 30th International Conference on Photonic, Electronic and Atomic Collisions (ICPEAC XXX), held in Cairns, Australia, from 26 July to 1 August 2017.

The authoritative historical archive contains 270 source files: 29 rendered source responses and 241 assets. Because GitHub Pages cannot display historical `.php` filenames as normal HTML pages, the restoration process additionally creates 25 text-only `.html` browser aliases while preserving the original `.php` files. Binary and other source assets remain byte-for-byte unchanged.

The generated site contains 295 website files before `.nojekyll` is added for publication.

The intended live site is <https://anatolikheifets.github.io/icpeac30-archive/>.
